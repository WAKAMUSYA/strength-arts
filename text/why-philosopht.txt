# Strength Arts

## 強さを極めるということ

強くなりたい。

アスリートにも、武道家にも、この願いは共通している。

もっと重いものを持ちたい。
もっと速く走りたい。
もっと遠くへ飛ばしたい。
もっと強く打ちたい。
もっと正確に動きたい。
もっと速く反応したい。
そして、試合に勝ちたい。

では、「強くなる」とは何だろう。

Strength Artsでは、強さを一つの完成された答えとして扱わない。

筋力を高めれば強くなる。
技術を磨けば強くなる。
身体を思い通りに扱えれば強くなる。

どれも間違いではない。

しかし、それだけで強さのすべてを説明できるとも考えない。

私たちは、強さを追求する。

そして、強さを追求する過程で現れる限界から、

**「そもそも強さとは何なのか」**

を何度でも問い直す。

それがStrength Artsの基本的な姿勢である。

# N → N+1

数学では、どれだけ大きな自然数 (N) を持ってきても、

[
N+1
]

が存在する。

100の次には101がある。

1億の次には1億1がある。

想像もできないほど巨大な数を持ってきても、その数に1を足すことができる。

だから、

[
N \rightarrow N+1 \rightarrow N+2 \rightarrow N+3 \rightarrow \cdots
]

と、どこまでも進むことができる。

トレーニングも、これによく似ている。

今の自分を (N) とする。

昨日より少し強くなる。

[
N\rightarrow N+1
]

さらに鍛える。

[
N+1\rightarrow N+2
]

筋力を高める。

速度を高める。

技術を磨く。

持久力を高める。

判断を速くする。

一つずつ改善していく。

これは、強くなるための基本である。

Strength Artsは、この積み重ねを否定しない。

むしろ大切にする。

簡単に、

「筋力ではない」

「技術ではない」

「もっと別の何かがある」

と考えるべきではない。

まず鍛える。

まず学ぶ。

まず反復する。

まず、

[
N\rightarrow N+1
]

を行う。

強さについて考えることと、実際に強くなることは別である。

身体を使い、試し、失敗し、修正する。

その積み重ねを飛ばして、強さの本質だけを手に入れることはできない。

# 極める

しかし、

[
N\rightarrow N+1
]

を繰り返していくと、いつか壁に出会う。

以前と同じ努力をしているのに、以前ほど伸びない。

もっと力を入れているのに、結果が変わらない。

もっと速く動こうとしているのに、かえって動きが崩れる。

もっと練習しているのに、試合では勝てない。

そこで、

「努力が足りない」

と考えることもできる。

実際、それが正しい場合も多い。

しかし、すべての壁が努力不足によって生まれるわけではない。

ここで「極限」という考え方が役に立つ。

数学における極限は、ある値へ限りなく近づいていくことを扱う。

ここではそれを、強さを考えるための比喩として使いたい。

ある方法を、

もっと。

さらに。

もっと正確に。

もっと速く。

もっと強く。

と追求していく。

つまり、その方法を**極めようとする**。

すると、その方向がどこへ向かっているのかが少しずつ見えてくる。

そして、ときには、

**「この方向をどれだけ進んでも、目的そのものには到達できないのではないか」**

ということが見えてくる。

それは失敗ではない。

むしろ、

**極めようとしたからこそ、その方法の輪郭が見えた**

のである。

# 二つの限界

Strength Artsでは、壁に出会ったとき、少なくとも二つの可能性を考える。

一つは、**能力の限界**。

もう一つは、**構造の限界**である。

能力の問題なら、その能力を高めればいい。

筋力が足りないなら筋力を鍛える。

技術が足りないなら反復する。

経験が足りないなら経験を積む。

判断が遅いなら、判断できる状況を何度も経験する。

これは、

[
N\rightarrow N+1
]

で解決できる。

しかし構造の限界は違う。

どれだけ (N+1) を繰り返しても、その方向そのものが目的とずれているなら、目的には届かない。

この違いを見分けることが重要になる。

# 柔道で考える

柔道で相手を投げたいとする。

最初は、

**もっと強い力を出す**

と考えるかもしれない。

筋力を高める。

より強く引く。

より強く押す。

身体全体を使う。

これは正しい。

筋力は間違いなく武器になる。

だから、

[
筋力:N\rightarrow N+1
]

を続ければいい。

しかし相手も強くなる。

相手も踏ん張る。

こちらが100の力を出せば、相手も100の力で抵抗する。

なら120。

さらに150。

それでも、体重も筋力も自分より上の相手は存在する。

ここで一つの壁が見える。

そこで問う。

**本当に「相手より大きな力を出すこと」が、相手を投げるための絶対条件なのか。**

相手が踏ん張れない方向ならどうか。

相手が動いている瞬間ならどうか。

相手が力を出そうとした瞬間ならどうか。

重心が支持できない位置にあるならどうか。

こちらが相手を動かすのではなく、相手自身の動きを利用したらどうか。

ここで、

**「もっと強くする」**

という問題が、

**「相手が投げられる条件とは何か」**

という問題へ変わる。

筋力を捨てたわけではない。

筋力が、強さを構成する一つの要素へ戻ったのである。

# Nの中身が変わる

ここで、Strength Artsにおける (N) をもう少し考えてみたい。

最初は、

[
N={筋力}
]

だったかもしれない。

強い人とは、力の強い人。

しかし競技を続けると、それだけでは説明できないことに出会う。

そこで、

[
N={筋力,速度,技術}
]

になる。

さらに経験を積む。

すると、

[
N=
{
筋力,
速度,
技術,
持久力,
判断,
知覚,
タイミング,
位置,
相手との関係,
\dots
}
]

と、強さを構成するものが増えていく。

ここには二種類の成長がある。

一つは、

**Nの値を高めること。**

筋力を上げる。

速度を上げる。

技術を高める。

つまり、

[
N\rightarrow N+1
]

である。

もう一つは、

**Nの定義そのものを更新すること。**

[
N\rightarrow N'
]

である。

以前は強さに含めていなかったものが、強さの一部として見えるようになる。

これは単なる能力向上ではない。

**強さを見る座標そのものが増えている。**

# 達人は「Nが大きい人」なのか

武道には、ときに不思議な言葉が残されている。

「勝ってから戦う」

「負けることをしない」

「力で争わない」

「先を取る」

こうした言葉は、説明を省略したまま伝わると、神秘的なものに見える。

しかし、Strength Artsでは可能な限り、それを現代の言葉へ戻して考えてみたい。

達人とは単純に、

**Nがものすごく大きい人**

なのだろうか。

もちろん、それもある。

長年の鍛錬によって、筋力も技術も感覚も高い。

しかし、それだけではない可能性がある。

初心者が、

[
N={筋力,技術}
]

で勝負を見ているとき、

熟練者は、

[
N'=
{
筋力,
技術,
距離,
位置,
タイミング,
相手の反応,
選択肢,
心理,
時間,
\dots
}
]

で同じ勝負を見ているのかもしれない。

つまり、

**計算能力が違うだけではなく、計算している変数そのものが違う。**

そう考えると、

「技を出す前に勝負は決まっている」

という言葉も違って聞こえてくる。

# 「勝ってから戦う」を考える

柔道の試合で考えてみる。

目的は、

[
\boxed{\text{ルール内で、規定時間内に勝つ}}
]

ことである。

これは変えない。

ここで、

「もっと強い技を出す」

ことだけを考えると、

[
技術:N\rightarrow N+1
]

を続けることになる。

もちろん必要である。

しかし、一段上から試合全体を見る。

組み手はどうか。

相手の姿勢はどうか。

自分と相手の位置はどうか。

相手が逃げられる方向はいくつあるか。

相手は次に何をしようとしているか。

自分の得意な形へ入っているか。

相手の選択肢を減らせているか。

こうした条件を整えていく。

すると、技を掛ける瞬間には、

**すでに勝敗の確率が大きくこちらへ傾いている**

という状態を作れる。

外から見ると、

[
技\rightarrow勝利
]

に見える。

しかし実際には、

[
条件形成
\rightarrow
条件形成
\rightarrow
条件形成
\rightarrow
技
\rightarrow
勝利
]

なのかもしれない。

そう考えると、

**「勝ってから戦う」**

という言葉は、単なる精神論ではなくなる。

勝利が起きやすい条件を、勝負が決まる瞬間より前に作っておく。

これなら、現代のアスリートにも理解できる。

# 剣道で考える

剣道でも同じことが起こる。

最初は、

**もっと速く打ちたい**

と考える。

だから速く振る。

反応を速くする。

踏み込みを速くする。

ここでも、

[
N\rightarrow N+1
]

が行われる。

しかし、相手も速い。

人間の反応速度にも限界がある。

そこで、

「相手が動いてから、それより速く反応する」

という競争だけを続けたらどうなるだろう。

どこかで厳しくなる。

そこで問いが変わる。

**相手が動いてから反応する必要はあるのか。**

相手が動こうとする兆候を捉えられないか。

相手が動かざるを得ない状況を作れないか。

打てる場所を限定できないか。

間合いを操作できないか。

こちらの働きかけによって、相手の選択を誘導できないか。

すると、

**「相手より速く反応する」**

から、

**「相手の動きが生まれる条件を扱う」**

へと、強さの定義が広がる。

速度を捨てたわけではない。

速度という変数を含んだ、より大きな (N') を見つけたのである。

# スポーツでも同じである

これは武道だけの話ではない。

ゴルフで、

「もっと遠くへ飛ばしたい」

とする。

最初は、

「もっと強く振ろう」

と考えるかもしれない。

しかし、力感を増やせばそのまま飛距離が伸びるわけではない。

そこで目的へ戻る。

[
\boxed{\text{ボールをより遠くへ飛ばす}}
]

これは固定する。

「強く振る」は手段である。

すると、

ボール初速。

打点。

打ち出し角。

スピン。

クラブの運動。

身体とクラブの関係。

それを成立させる身体状態。

と、見るべき変数が増えていく。

同じことは、投球、跳躍、スプリント、ハンドボールのシュートにも言える。

「もっと力を出す」

だけではなく、

**欲しい結果が生じるためには、何が成立していなければならないのか。**

結果から逆算すると、これまで見えていなかった (N) の中身が見えてくる。

# 目的は固定する。勝ち方は固定しない

ただし、前提を疑うことには注意が必要である。

柔道で、

「勝つ必要すらない」

まで行ってしまえば、それは一つの哲学にはなる。

しかし、柔道の試合に勝つという問題は解決していない。

剣道でも同じである。

スポーツでも同じである。

競技には目的と制約がある。

だから、Strength Artsではまず、

[
\begin{cases}
目的\
制約
\end{cases}
]

を明確にする。

柔道なら、

[
\begin{cases}
目的：試合に勝つ\
制約：柔道のルール、試合時間
\end{cases}
]

ここは固定する。

疑うのは、その内側にあるものだ。

「強くなければ勝てない」

「速くなければ勝てない」

「この技でなければならない」

「自分から攻めなければならない」

「相手より多くの技を知らなければならない」

それらは本当に絶対条件なのか。

だから、

**勝つことは固定する。
勝ち方は固定しない。**

目的を捨てるのではなく、目的へ到達する方法を自由にするのである。

# 前提を外す

「前提を疑え」

という言葉は簡単である。

しかし実際には難しい。

なぜなら、前提とは、

**自分が疑う対象として認識していないもの**

だからだ。

そこで、壁が役に立つ。

なぜ、これ以上進まないのか。

何を+1し続けているのか。

そもそも、それを+1する理由は何だったのか。

それを使えないとしたら、どうするか。

逆の方法で同じ結果を出せないか。

こうして考えていくと、

「自分はこれを当然だと思っていた」

というものが少しずつ見えてくる。

だからStrength Artsでは、

**前提を外すことより、まず前提を発見すること**

を重視する。

# 無限から学ぶ

自然数には最後がない。

どれだけ大きな (N) に到達しても、

[
N+1
]

が存在する。

だから、どこかに存在する「最後の自然数」を目指して進み続けても、それには到達できない。

そこで数学では、

[
1,2,3,4,\dots
]

と進み続けるだけではなく、

[
\mathbb{N}={1,2,3,4,\dots}
]

と、その全体を一つの対象として見ることができる。

Strength Artsでは、この構造を強さの探究に重ねて考える。

もっと筋力を。

もっと速度を。

もっと技術を。

もっと正確に。

もっと速く。

そうやって進む。

しかし、ときには一度止まり、

**「自分は何を+1し続けているのか」**

を見る。

前へ進むのではなく、

**進んできた道そのものを見る。**

すると、

[
N
]

だと思っていたものが、強さの一部分にすぎなかったと気づくことがある。

そこで、

[
N\rightarrow N'
]

が起こる。

強さの定義が更新される。

# 強さの探究は螺旋になる

ここまでを一つの流れにすると、

[
\boxed{
N
\rightarrow
N+1
\rightarrow
N+2
\rightarrow
\cdots
\rightarrow
極限
\rightarrow
Nの再定義
\rightarrow
N'
\rightarrow
N'+1
\rightarrow
\cdots
}
]

となる。

まず鍛える。

[
N\rightarrow N+1
]

極めようとする。

すると、その方法の極限が見えてくる。

そこで、自分が何を強さとして数えていたのかを見る。

そして、

[
N\rightarrow N'
]

強さを再定義する。

新しい変数が見つかる。

新しい身体の使い方が見つかる。

新しい戦い方が見つかる。

新しいトレーニングが見つかる。

しかし、そこで終わりではない。

新しい世界でも、

[
N'\rightarrow N'+1
]

を始める。

また鍛える。

また反復する。

また極めようとする。

そして、また壁に出会う。

そこで再び問い直す。

この循環は終わらない。

だから、強さの探究は一直線ではない。

**螺旋である。**

# Strength Arts

Strength Artsは、「正しい強さ」を一つに決めることを目的としない。

筋力は重要である。

速度も重要である。

技術も重要である。

身体操作も重要である。

知覚も、判断も、タイミングも、相手との関係も重要である。

しかし、それらのどれか一つを「強さの正体」と決めた瞬間、また新しい前提が生まれる。

だから私たちは、まず鍛える。

極めようとする。

そして壁に出会う。

壁に出会ったら、ただ「もっと」と考えるだけではなく、

**何を+1し続けているのか**

を見る。

その+1の先に目的があるなら、さらに進めばいい。

そうでないなら、一段上から見る。

そして必要なら、

[
N\rightarrow N'
]

強さそのものを再定義する。

達人とは、単純に (N) が大きい人ではないのかもしれない。

長い鍛錬の中で何度も極限に触れ、そのたびに自分が見ている (N) を更新してきた人なのかもしれない。

だから初心者と達人では、同じ動きを見ても見えているものが違う。

同じ勝負をしていても、扱っている変数が違う。

同じ「強さ」という言葉を使っていても、その中身が違う。

私たちが目指したいのは、ただ一つの数値を大きくすることではない。

もちろん、数値は伸ばす。

身体も鍛える。

技術も磨く。

勝つために努力する。

そのうえで、

**自分が強さだと思っているものそのものを、何度でも更新できる人間でありたい。**

[
N\rightarrow N+1
]

そして極限へ。

壁を知る。

自分が何を (N) としていたのかを知る。

必要なら、

[
N\rightarrow N'
]

へ。

そしてまた、

[
N'\rightarrow N'+1
]

を始める。

**極める。
限界を知る。
強さを問い直す。
そして、また極める。**

Strength Artsとは、その終わりのない強さの探究である。
