# Strength Arts Practice

## 強さを現場でつくる

Strength Artsには、強さについての思想がある。

そして、その思想を探究するためのMethodがある。

しかし、思想と方法論だけでは選手は強くならない。

競技者が必要としているのは、

速く走れること。

遠くへ投げられること。

強く打てること。

相手を崩せること。

一本を取れること。

試合に勝てること。

つまり、

**結果である。**

Strength Artsの思想は、最後には必ず身体と競技へ戻らなければならない。

そのための実践を、ここでは考える。

# 選手を「能力の集合」として見ない

選手を見るとき、私たちは分類をしたくなる。

筋力が弱い。

身体が硬い。

スピードがない。

体幹が弱い。

技術が足りない。

もちろん、これらの評価は必要である。

しかしStrength Artsでは、評価する前に一つ確認する。

**その能力は、何のために必要なのか。**

たとえば、ジャンプ力が低い選手がいる。

そこで、

「ジャンプ力を上げよう」

と考える。

しかし、その選手がハンドボール選手なら、本当に必要なのは垂直跳びの記録を伸ばすことではないかもしれない。

シュート時にDFより高い位置を取ること。

空中で時間を作ること。

接触されても姿勢を維持すること。

適切なタイミングで跳ぶこと。

これらによって得点率を上げること。

ジャンプ力は、そのための一つの変数である。

だからStrength Artsでは、

[
能力\rightarrow競技
]

だけではなく、

[
競技結果\Leftarrow必要条件\Leftarrow能力
]

と逆方向からも選手を見る。

# 1．最初に結果を見る

指導を始めるとき、最初の問いは、

**「何ができないのか？」**

ではない。

まず、

**「何をできるようにしたいのか？」**

を見る。

たとえば、

「シュートを決めたい」

「当たり負けしたくない」

「300y飛ばしたい」

「一本を取りたい」

「切り返しを速くしたい」

「相手を崩したい」

という結果がある。

これを、

[
R
]

とする。

ResultのRである。

Strength Artsの指導は、

[
R=?
]

から始める。

# 2．Rが成立する条件を分解する

次に、

**「その結果が起きるためには、何が成立していなければならないか？」**

を考える。

たとえば剣道で、

[
R=\text{面で一本を取る}
]

とする。

一本が成立した場面を考える。

十分な打突が必要である。

適切な間合いが必要である。

相手より有利なタイミングが必要である。

相手の防御を突破する必要がある。

姿勢や残心も競技上必要になる。

さらに、

「なぜその瞬間に面が空いたのか」

まで遡る。

相手が別の場所を警戒していたのか。

こちらの働きかけに反応したのか。

相手が攻撃しようとした瞬間だったのか。

すると、

[
R
\Leftarrow
{
技術,
速度,
間合い,
タイミング,
相手の反応,
姿勢,
判断,
\dots
}
]

という構造が見えてくる。

これが、その競技場面における現在の (N) である。

# 3．「できない」を分解する

選手はよく、

「できません」

と言う。

しかし、「できない」は原因ではない。

たとえば、

**相手を抜けない。**

なぜか。

速度が足りないのか。

加速が足りないのか。

フェイントが読まれているのか。

相手との距離が悪いのか。

動き始めるタイミングが悪いのか。

相手がこちらの選択肢を予測できる状態になっているのか。

そもそも、抜く必要がない場面で抜こうとしているのか。

同じ「抜けない」でも、必要なトレーニングはまったく違う。

だからStrength Artsでは、

[
できない
]

を、そのままトレーニング課題にしない。

[
できない
\rightarrow
なぜ？
\rightarrow
必要条件
\rightarrow
介入可能な変数
]

まで分解する。

# 4．ボトルネックを探す

Nの中には、多くの変数がある。

[
N=
{
筋力,
速度,
技術,
知覚,
判断,
タイミング,
位置,
\dots
}
]

しかし、全部を同時に鍛えることはできない。

そこで、

**今もっとも結果を制限しているものは何か**

を探す。

これをボトルネックと考える。

たとえば、

筋力100
技術80
速度85
判断90

の選手がいたとしても、単純に「筋力が高いから筋力は不要」とは言えない。

逆も同じである。

重要なのは、

**どの変数を変えたときにRが最も変わるか。**

つまり、

[
\frac{\Delta R}{\Delta N}
]

を見る。

難しい数式に見えるが、意味は単純である。

**「どこを少し変えると、結果が大きく変わるか？」**

ということである。

Strength Artsの指導では、ここを探す。

# 5．最小の介入を試す

ボトルネックの仮説ができたら、すぐに大規模なプログラムを組む必要はない。

まず、小さく変える。

立ち位置を変える。

タイミングを変える。

力の入れ方を変える。

視線を変える。

動作の一部分を変える。

負荷を変える。

一つだけ条件を変える。

そして、

[
Before\rightarrow Intervention\rightarrow After
]

を見る。

結果が変わったなら、その変数は重要である可能性が高い。

変わらなければ、仮説を修正する。

この小さな実験を繰り返す。

# 6．「感覚」もデータとして扱う

スポーツ科学では、測定できるものが重要である。

Strength Artsもそれを重視する。

しかし、身体には外から測りにくい情報もある。

「軽かった」

「勝手に動いた」

「相手が遅く見えた」

「力を入れていないのに飛んだ」

「いつもより地面を感じた」

こうした感覚を、Strength Artsでは捨てない。

ただし、

**感覚をそのまま事実にはしない。**

たとえば、

「脱力したら飛んだ」

と感じた。

なら、

[
仮説=\text{力感を下げると飛距離が伸びる}
]

と置く。

そして測る。

本当に飛距離が伸びたか。

ヘッドスピードはどうだったか。

再現できるか。

別の日でも起こるか。

感覚は、

**答えではなく仮説を生むセンサー**

として扱う。

# 7．科学も同じように扱う

論文に書かれていることも重要である。

筋肥大。

最大筋力。

RFD。

SSC。

疲労。

運動学習。

反応時間。

こうした知見は、非常に強力な道具になる。

しかし、

「研究で効果がある」

と、

「この選手の、この競技場面の、この問題を解決する」

は同じではない。

だから科学的知見も、

[
Knowledge\rightarrow Hypothesis\rightarrow Practice
]

へ戻す。

科学を否定しない。

科学を権威として終わらせない。

**使う。**

# 8．達人の感覚も同じように扱う

同じことを、武道の伝承にも行う。

「力を抜け」

と言われた。

そのまま信じるのではない。

否定するのでもない。

何が起きているのかを見る。

筋活動が変わったのか。

拮抗筋の緊張が減ったのか。

動作速度が変わったのか。

相手に力の方向を読まれにくくなったのか。

接触の仕方が変わったのか。

タイミングが変わったのか。

あるいは、まだ説明できない別の何かなのか。

分からないなら、

**分からないまま試す。**

Strength Artsでは、

「説明できない」

と、

「存在しない」

を同じにしない。

しかし、

「説明できない」

と、

「何を言ってもよい」

も同じにしない。

現象を残し、仮説を作り、検証する。

# 9．指導では「答え」より条件を与える

指導者が、

「右足をこうしろ」

「肩をもっとこうしろ」

「力を抜け」

と答えを与え続けると、選手は指導者のNの中で動くことになる。

Strength Artsでは、必要に応じて**条件を与える。**

たとえば、

「もっと速く動け」

ではなく、

**相手が右へしか逃げられない状況を作ってみる。**

「力を抜け」

ではなく、

**今の半分の力感で同じ結果を出してみる。**

「反応を速くしろ」

ではなく、

**相手が動く前に分かる情報を探してみる。**

すると選手自身が探索を始める。

指導者が答えを教えるだけではなく、

**Nが変わる環境を作る。**

# 10．制約を使ってNを広げる

ここで「制約」がトレーニングになる。

たとえば柔道で、

**筋力で押し切ることを禁止する。**

剣道で、

**相手が動いてから反応することを禁止する。**

球技で、

**得意な方向への突破を禁止する。**

すると、それまで使っていなかった変数を使わざるを得なくなる。

[
N=
{筋力,速度}
]

だけでは解けなくなる。

そこで、

[
N'=
{筋力,速度,タイミング,位置,誘導,\dots}
]

が必要になる。

つまり、制約は選手を不自由にするためだけにあるのではない。

**新しい自由を発見させるために使うことができる。**

# 11．N+1とN→N'を混同しない

ここは指導上とても重要である。

選手が新しい考え方を知った。

「力を抜くことが大切なんだ」

「タイミングなんだ」

「位置関係なんだ」

と気づいた。

しかし、

**気づいたことと、できることは違う。**

N'を発見しただけでは強くなっていない。

そこから、

[
N'\rightarrow N'+1
]

が必要になる。

新しい感覚を反復する。

新しいタイミングを練習する。

新しい戦術を試合形式で使う。

プレッシャー下で再現する。

疲労状態でも再現する。

異なる相手にも使う。

ここで初めて、新しいNが能力になる。

だからStrength Artsは、

**発見と鍛錬を往復する。**

# 12．再現性を上げる

一度できたことを「できる」とは考えない。

偶然かもしれない。

相手が違えばできないかもしれない。

疲れていたらできないかもしれない。

だから、

[
1回
\rightarrow
数回
\rightarrow
反復
\rightarrow
条件変更
\rightarrow
競技
]

と段階を上げる。

Strength Artsにおける「できる」は、

**必要な状況で再現できる**

ことへ近づけていく。

# 13．競技へ戻す

トレーニングは競技そのものではない。

スクワットが強くなった。

ジャンプが高くなった。

反応課題が速くなった。

身体操作が上手くなった。

それだけでは終わらない。

最後に、

[
Training\rightarrow Competition
]

が起きたかを見る。

柔道なら勝負へ。

剣道なら一本へ。

球技なら得点・失点へ。

ゴルフならショットへ。

陸上ならタイムへ。

Strength Artsでは、

**トレーニングの成功と競技の成功を区別する。**

トレーニングの数字が伸びても、競技結果が変わらなければ、

[
N
]

の捉え方をもう一度疑う。

# 指導の基本ループ

ここまでを、現場で使える形まで縮める。

まず、

[
\boxed{R}
]

**何を起こしたい？**

次に、

[
\boxed{N}
]

**その結果を決めているものは何だと思う？**

そして、

[
\boxed{N\rightarrow N+1}
]

**まず鍛える。**

結果を見る。

[
\boxed{\Delta R}
]

**変わったか？**

変わったなら続ける。

変わらないなら、

[
\boxed{極限?}
]

**努力不足か、それとも軸が違うのか？**

そこで、

[
\boxed{R\Leftarrow ?}
]

**結果から逆算する。**

新しい変数が見つかったら、

[
\boxed{N\rightarrow N'}
]

そしてまた、

[
\boxed{N'\rightarrow N'+1}
]

鍛える。

最後に競技へ戻す。

[
\boxed{
R
\rightarrow
N
\rightarrow
N+1
\rightarrow
検証
\rightarrow
極限
\rightarrow
N'
\rightarrow
N'+1
\rightarrow
R
}
]

この循環がStrength Arts Practiceの基本になる。

# 指導者は「Nを決める人」ではない

Strength Artsにおける指導者は、選手に正しいNを教える人ではない。

なぜなら、私たち自身もNのすべてを知っているわけではないからである。

指導者が持っている知識も、

[
N_{coach}
]

にすぎない。

選手には選手の、

[
N_{athlete}
]

がある。

科学には科学が発見したNがある。

武道の伝承には、長い実践の中で発見されたNがある。

競技には、その競技特有のNがある。

Strength Artsは、それらを集める。

比較する。

試す。

そして更新する。

だから指導者が言うべきことは、ときに、

「これが正しい」

ではなく、

**「これを試してみよう」**

である。

# 強さを教えるのではなく、強くなる能力を育てる

選手にはいつか、指導者がいない瞬間が来る。

試合中に、

「今はNを再定義しよう」

とコーチが説明することはできない。

相手が変わる。

環境が変わる。

身体の状態が変わる。

想定していなかったことが起きる。

そのとき必要なのは、覚えた正解だけではない。

自分で感じる。

試す。

結果を見る。

修正する。

必要なら、考え方そのものを変える。

つまり、

**自分自身でStrength Arts Methodを回せること。**

それが最終的な指導目標の一つになる。

# Strength Arts Practice

私たちは、選手を型にはめるために指導しない。

かといって、

「自由にやればいい」

とも考えない。

科学を使う。

測定する。

基本を鍛える。

技術を反復する。

先人から学ぶ。

達人の言葉にも耳を傾ける。

選手自身の感覚も拾う。

そして、それらをすべて、

[
仮説
]

として競技へ持っていく。

結果を見る。

うまくいけば磨く。

うまくいかなければ修正する。

壁が来れば、その壁を見る。

もっと鍛えるべきなら鍛える。

しかし、同じNを上げ続けても目的に近づかないなら、

[
N\rightarrow N'
]

を探す。

そして新しいNを見つけても、そこで満足しない。

また、

[
N'\rightarrow N'+1
]

を始める。

考える。

鍛える。

試す。

競う。

測る。

また考える。

Strength Artsの実践とは、

**思想を身体へ落とし、身体から得た結果によって思想を更新し続けること**

である。

そして最終的には、選手自身がその循環を回せるようにする。

ただ強い選手をつくるのではない。

**自分で強くなり続けられる選手を育てる。**

それが、Strength Artsの指導である。
