# Strength Arts Method

## 強さを探究する方法

Strength Artsでは、強さを固定されたものとして考えない。

現在の強さを (N) とするなら、まず行うことは単純である。

[
N\rightarrow N+1
]

鍛える。

練習する。

学ぶ。

測る。

改善する。

しかし、それを続けて壁に出会ったとき、ただ同じ方向へ努力量を増やすだけではなく、

[
N\rightarrow N'
]

という可能性を考える。

つまり、

**「もっと強くなる」だけではなく、「自分が強さだと思っているものは十分なのか」を問い直す。**

Strength Arts Methodとは、そのための方法である。

# 1．目的を固定する

最初に決めるのは、トレーニング方法ではない。

**何を起こしたいのか。**

である。

たとえば柔道なら、

「強い選手になる」

では曖昧すぎる。

試合について考えるなら、

[
Goal=\text{規定時間内に試合に勝つ}
]

とする。

ゴルフなら、

[
Goal=\text{300y飛ばす}
]

かもしれない。

スプリンターなら、

[
Goal=\text{100mのタイムを縮める}
]

になる。

剣道なら、

[
Goal=\text{試合で有効打突を取る}
]

と置くことができる。

ここで大切なのは、

**目的と手段を混ぜないこと。**

「速く振る」

「筋力をつける」

「脱力する」

「体幹を強くする」

これらは目的ではない。

目的を達成するための仮説である。

# 2．制約を固定する

目的だけでは、問題の外へ出ることができてしまう。

柔道で、

「勝つ必要なんてない」

と言ってしまえば、確かに勝敗からは自由になれる。

しかし、柔道の試合に勝つという問題は解いていない。

だからStrength Artsでは、目的と同時に**制約**を定義する。

[
\begin{cases}
Goal=\text{試合に勝つ}\
Constraint=\text{競技ルール、試合時間、階級}
\end{cases}
]

この枠は守る。

その中で自由に考える。

つまり、

**目的は固定する。
制約は守る。
方法は固定しない。**

これがStrength Arts Methodの基本原則になる。

# 3．現在のNを書く

次に、

**「自分は現在、何が結果を決めていると思っているのか」**

を書き出す。

たとえば柔道なら、

[
N=
{
筋力,
速度,
技術,
持久力
}
]

と考えているかもしれない。

ゴルフなら、

[
N=
{
筋力,
ヘッドスピード,
スイング技術
}
]

かもしれない。

重要なのは、この時点で完璧なNを作ろうとしないことである。

むしろ、

**現在の自分が世界をどう見ているか**

を明らかにする。

Nは答えではない。

**現在の仮説である。**

# 4．N→N+1を行う

Nが見えたら、まず鍛える。

[
N\rightarrow N+1
]

筋力が重要だと思うなら、筋力を伸ばす。

速度なら速度を伸ばす。

技術なら技術を磨く。

判断なら判断を鍛える。

ここでは奇抜な発想を求めない。

すでに効果が確認されているトレーニングがあるなら、それを使う。

科学的知見があるなら利用する。

優れた指導法があるなら学ぶ。

先人が何十年も積み上げてきた技術があるなら尊重する。

Strength Artsは、

**「既存の方法を疑うための思想」ではない。**

既存の方法を使い切る。

そのうえで、その方法がどこへ向かうのかを見る。

# 5．測る

「強くなった気がする」

だけでは不十分である。

可能なものは測る。

重量。

速度。

タイム。

飛距離。

球速。

成功率。

試合結果。

反応時間。

反復回数。

測れないものもある。

しかし、測れないからといって、何でもよいわけではない。

映像を見る。

対戦結果を見る。

条件を変えて試す。

本人の感覚を記録する。

第三者が観察する。

Strength Artsでは、

[
仮説\rightarrow実践\rightarrow結果
]

を可能な限り切り離さない。

なぜなら、

**Nが本当に重要な変数なのかを知るため**

である。

# 6．壁を見つける

N+1を続けていると、壁が現れる。

ここで、すぐに新しい理論へ飛びつかない。

まず問う。

**これは単なる能力不足ではないか。**

練習量が足りないだけではないか。

技術が未熟なだけではないか。

筋力が不足しているだけではないか。

回復できていないだけではないか。

ここで解決できるなら、

[
N\rightarrow N+1
]

を続ければいい。

しかし、十分に改善しているにもかかわらず、目的に近づかない。

あるいは、

[
\Delta N
]

に対して、

[
\Delta Result
]

が極端に小さくなっていく。

そこで初めて、

**「この軸そのものを見直す必要があるのではないか」**

と考える。

ここが、極限を見る瞬間である。

# 7．Nから離れる

ここからStrength Arts Methodの特徴的な部分に入る。

これまで、

[
N\rightarrow N+1
]

と前へ進んできた。

ここで一度、進むことを止める。

そして、

[
N
]

そのものを見る。

問いは単純である。

**「私は何を+1し続けていたのか？」**

筋力か。

速度か。

技術か。

力感か。

反応速度か。

フォームの完成度か。

そしてもう一つ問う。

**「なぜ、それを+1しようとしていたのか？」**

ここで、手段と目的をもう一度分離する。

# 8．結果から逆算する

前提を外すことは難しい。

なぜなら、前提は本人にとって「当然」だからである。

そこでStrength Artsでは、一度現在の解法を消す。

そして、**結果側から考える。**

柔道なら、

> 理想的に相手を投げられた瞬間、何が成立している必要があるか。

剣道なら、

> 有効打突が成立した瞬間、何が起きている必要があるか。

ゴルフなら、

> 300y飛んだボールには、何が起きている必要があるか。

そこから逆算する。

たとえば、

[
Result
\Leftarrow
技術的条件
\Leftarrow
身体的条件
\Leftarrow
環境・相手との関係
]

と辿る。

ここでは、

「自分はどう動けばいい？」

から始めない。

**「結果が成立するには何が必要か？」**

から始める。

# 9．現在の解法を禁止する

それでも前提が見えないなら、現在の解法を一度禁止してみる。

柔道で、

「もっと筋力をつければいい」

と思っているなら、

**これ以上筋力を上げてはいけない。それでも勝率を上げるには？**

と考える。

剣道で、

「もっと速く反応する」

なら、

**反応速度を上げずに一本を取るには？**

と考える。

すると、

間合い。

予測。

誘導。

相手の選択肢。

タイミング。

先。

といった、それまで背景にあった変数が前へ出てくる。

現在の方法を否定するためではない。

**現在の方法によって隠れていたものを見るため**

である。

# 10．逆を考える

さらに、

**「逆でも成立するか？」**

と考える。

もっと力を入れる。

なら、

**力感を減らしても同じ結果を出せるか。**

もっと速く反応する。

なら、

**反応しなくてもよい状況を作れないか。**

相手を動かす。

なら、

**相手自身に動いてもらえないか。**

この問いには、正しい答えがなくてもいい。

目的は、

**思考を固定している前提を露出させること**

だからである。

# 11．Nを再定義する

ここまで来ると、それまで見えていなかった変数が現れることがある。

たとえば、

[
N=
{
筋力,
速度,
技術
}
]

だったものが、

[
N'=
{
筋力,
速度,
技術,
知覚,
タイミング,
位置,
相手の反応,
選択肢
}
]

になる。

これが、

[
N\rightarrow N'
]

である。

強くなったわけではない。

まだ何も身についていない。

ただ、

**強さについての地図が更新された。**

ここを混同してはいけない。

新しい理論を知ったことは、強くなったことではない。

# 12．再びN'+1へ戻る

新しい変数を発見したら、また現場へ戻る。

[
N'\rightarrow N'+1
]

タイミングが重要だと思うなら、タイミングを鍛える。

知覚なら知覚を鍛える。

位置関係なら、位置関係を練習する。

相手の反応を利用するなら、その状況を何度も作る。

そして測る。

本当に結果が変わったか。

変わらなければ、

**N'が間違っていた可能性を認める。**

Strength Artsでは、新しい考え方だから正しいとは考えない。

神秘的だから正しいとも考えない。

科学的に聞こえるから正しいとも考えない。

達人が言ったから正しいとも考えない。

自分が強く感じたから正しいとも考えない。

試す。

観察する。

測る。

そして更新する。

# 達人の言葉も仮説に戻す

武道には、多くの言葉が残されている。

「先を取る」

「勝ってから戦う」

「力を抜く」

「相手と争わない」

「無心」

Strength Artsでは、これらを否定しない。

しかし、そのまま信仰もしない。

たとえば、

**「勝ってから戦う」**

なら、

「試合開始前から精神的に勝利している」

と解釈することもできる。

しかし別の可能性もある。

[
勝利
\Leftarrow
技
\Leftarrow
有利な位置
\Leftarrow
相手の選択肢の制限
\Leftarrow
その前の働きかけ
]

という構造を表現していたのかもしれない。

ならば、

**「技を出す前に、勝利確率をこちらへ偏らせておく」**

と現代語へ翻訳できる。

そして、それを実際に検証する。

達人の言葉を神秘化するのではない。

切り捨てるのでもない。

**検証可能な仮説へ戻す。**

これもStrength Arts Methodの役割である。

# 指導者の役割

この方法を採用すると、指導者の役割も少し変わる。

指導者は、

**正解を知っている人**

だけではなくなる。

もちろん、知識は必要である。

経験も必要である。

技術も必要である。

しかし、それ以上に、

**選手が現在どのNを見ているのかを見抜く人**

になる。

選手が筋力を+1すべきなら、筋力を鍛える。

技術を+1すべきなら、技術を磨く。

しかし、同じNを上げ続けても結果が変わらないなら、

「もっと頑張れ」

だけでは終わらない。

一緒にNを見る。

何を前提にしているのか。

本当の目的は何か。

結果が成立する条件は何か。

そして必要なら、

[
N\rightarrow N'
]

を促す。

ただし、指導者がN'を押し付けるのではない。

選手自身が、

**「あ、自分はこれしか見ていなかった」**

と気づける状況を作る。

それが、Strength Artsにおける指導の一つの理想である。

# Strength Arts Method

Strength Arts Methodをまとめる。

### 目的を固定する

何を起こしたいのか。

### 制約を固定する

何を守らなければならないのか。

### 現在のNを見る

何が結果を決めていると考えているのか。

### N+1する

まず鍛える。

### 測る

本当に結果へ近づいているか。

### 極限を見る

努力不足なのか、その軸の限界なのか。

### Nそのものを見る

何を+1し続けていたのか。

### 結果から逆算する

欲しい結果が成立する条件は何か。

### 前提を露出させる

現在の解法を禁止する。逆を考える。

### Nを再定義する

[
N\rightarrow N'
]

### 新しいNを鍛える

[
N'\rightarrow N'+1
]

### 検証する

本当に強くなったのか。

そしてまた、

[
N'+1
\rightarrow
N'+2
\rightarrow
\cdots
]

と進む。

壁が来れば、また問い直す。

だからStrength Arts Methodには、完成形がない。

[
\boxed{
目的
\rightarrow
N
\rightarrow
N+1
\rightarrow
極限
\rightarrow
N'
\rightarrow
N'+1
\rightarrow
検証
\rightarrow
\cdots
}
]

この循環を続ける。

# 極めるために、疑う

Strength Artsは、疑うことから始めない。

**まず極めようとする。**

極めようとするから、限界が見える。

限界が見えるから、前提が見える。

前提が見えるから、初めて疑うことができる。

そして前提を外したら、考えて終わりではない。

また鍛える。

また試す。

また競う。

また失敗する。

また測る。

思想は、身体へ戻さなければならない。

だからStrength Arts Methodは、

**考えるための方法であると同時に、鍛えるための方法である。**

[
N\rightarrow N+1
]

極める。

壁を見る。

[
N\rightarrow N'
]

強さを更新する。

そしてまた、

[
N'\rightarrow N'+1
]

極め始める。

この循環を、私たちは強さの探究と呼ぶ。
